# Common Web Validation

General validation checklist applicable to enterprise web pages regardless of project stage, CMS platform, or localization workflow.

---

## Purpose

This checklist covers common quality validation activities performed throughout the software delivery lifecycle.

It can be used independently or alongside specialized technical and localization QA checklists.

---

### Content Validation

- [ ] No missing content
- [ ] No duplicated content
- [ ] Consistent formatting
- [ ] Correct typography
- [ ] Proper heading hierarchy (if applicable)

---

### Navigation

- [ ] Internal links
- [ ] External links
- [ ] PDF documents
- [ ] Redirects
- [ ] Navigation menus function correctly

---

### Media Validation

- [ ] Images displayed correctly
- [ ] No broken images
- [ ] Alt text available where required
- [ ] Embedded media loads correctly (if applicable)

---

### Accessibility Quick Checks

- [ ] Images contain meaningful alt text
- [ ] Interactive elements are accessible
- [ ] Basic keyboard navigation works
- [ ] Visible keyboard focus indicators
- [ ] Sufficient colour contrast (basic visual check)

---

### Responsive Validation

Validate the page on the devices required by the project (Desktop, tablet and/or mobile)


Check for:
- [ ] Layout integrity
- [ ] Text truncation
- [ ] Overlapping elements
- [ ] Responsive navigation
- [ ] Component behaviour

---

### Browser Compatibility

Validate on browsers required by the project.

- [ ] Google Chrome
- [ ] Microsoft Edge
- [ ] Mozilla Firefox (if required)
- [ ] Safari (if required)

---

### General QA

- [ ] No visual regressions
- [ ] No unexpected behaviour
- [ ] No JavaScript console errors (if applicable)
- [ ] No broken functionality observed
- [ ] Ready for the next validation stage

---

#### Notes

Project-specific validation rules should always take precedence over this generic checklist.
