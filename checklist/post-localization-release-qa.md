# post-localization-release-qa.md
Functional and localization validation checklist performed after the translation process and before production release.

## Purpose

This checklist validates localized pages before global publication.

The goal is to ensure translated content is complete, visually correct and production-ready.

---

# Translation Validation

- [ ] All text translated
- [ ] No untranslated strings
- [ ] No placeholder text
- [ ] Alt text translated

---

# Preview Validation

Check at least a representative sample of locales depending on project requirements.

Recommended:
- 2–3 languages manually

Preferred:
- All the languages requested for this page workflow.

---

# Functional Validation

- [ ] Internal links
- [ ] External links
- [ ] PDF files
- [ ] Forms
- [ ] Contact modules

Tip:
Open external websites, PDF files, and forms in a separate browser tab whenever required by your organization's QA guidelines.

---

# Localization Validation

- [ ] Currency formatting 
- [ ] Date formatting
- [ ] Locale consistency
- [ ] Text expansion
- [ ] Layout integrity

Tip:
Verify that currency formatting follows ISO 4217, Unicode CLDR, and BCP 47 recommendations, while also respecting your organization's localization guidelines.

---

# Visual QA

- [ ] Desktop
- [ ] Tablet (if applicable)
- [ ] Mobile (if applicable)

Check for:

- Broken layouts
- Overlapping text
- Cropped images
- Unexpected spacing
- Text truncation

---

# Release Readiness

- [ ] No Critical defects
- [ ] No High defects
- [ ] Localization approved
- [ ] Functional validation complete
- [ ] Ready for production release
