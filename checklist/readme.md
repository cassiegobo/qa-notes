# QA Checklists
This directory contains reusable QA checklists based on enterprise web testing practices. 

The documents are technology-agnostic and focus on structured validation workflows commonly used in multilingual CMS environments.

### Files

#### common-web-validation.md
Generic validation steps applicable to most enterprise web pages.

#### pre-localization-tech-qa.md
Technical validation performed before localization or translation begins.

#### post-localization-release-qa.md
Functional and localization validation performed before release.

### Purpose
These checklists are intended as reusable templates for manual QA activities, release validation, and localization testing.

They are based on general industry practices and personal professional experience, without including proprietary client information.

### Notes
The checklists are designed to be adapted to different CMS platforms, projects, and release processes rather than followed as rigid procedures.
