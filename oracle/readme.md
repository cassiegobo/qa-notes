# Oracle Website Validation

Manual Enterprise Web QA validation performed on Oracle's public website using a standardized documentation workflow.

---

## Objective
Evaluate whether selected Oracle public pages meet basic release readiness criteria through manual validation focused on:

- Functional behaviour
- Localization
- Accessibility
- Responsive behaviour
- Content quality
- Release validation

---

## Validation Scope

### Website: 
https://www.oracle.com/

### Pages
- Landing page (https://www.oracle.com/government/)
- Education page (https://www.oracle.com/government/education/)
- One additional public page (TBD)

### Locales
The following locales are validated whenever available:

- English (EN)
- German (DE)
- Brazilian Portuguese (PT-BR)
- Japanese (JA)
- Chinese (ZH-CN)
- Arabic (AR)
